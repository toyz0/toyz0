🧠 How I approach software

I prefer software that solves an actual problem over software that exists just to demonstrate a technology.

A few principles I tend to work by:

* 🎯 Understand the problem before choosing the technology.
* 🧩 Keep architecture as simple as the problem allows.
* ⚙️ Automate repetitive work, not human judgment.
* 🔐 Treat security, maintainability, and data quality as engineering concerns from the beginning.
* 🤖 Use AI aggressively for productivity, but review its output like any other code.
* 🛠️ Build something small and useful before building something large and impressive.
